# 検証記録と実機試験

## このリポジトリで実施済み

2026-11-01、Codex cloud environmentで実施。結果は `downloads/reports/` に保存しています。

|確認|結果|
|---|---|
|KiCad 9.0.2 ERC|0件|
|KiCad DRC / 未接続|0件 / 0件|
|回路図XMLとPCBの照合|377個の番号付きパッドを確認、意図的NCも照合|
|外形・層数・実装面|98 × 98 mm、4層、全107フットプリントTOP|
|BOMとCPL|SMT 100個のDesignator一致、ヘッダ・穴を除外|
|Arm GCC|Cortex-M7 hard-float、ELF/BIN/HEX生成成功|
|DSP単体|7音程のYIN検出、スケール選択、無音、NaN/範囲処理、長時間有限出力|
|デジタルDRY|入力floatと出力のバイト一致、24 bit整数→float→整数のサンプル照合|
|メモリ安全性|ホストのAddressSanitizer / UndefinedBehaviorSanitizerで検出なし|
|出力FFT|±12、+7、−5半音および単音補正2条件、全6条件で目標±15 cents以内|

FFTテストは3秒の合成正弦波を処理し、最初の1秒を除いた2秒を解析。今回の結果では全6条件で誤差1 cent未満です。音声・和音・過渡音の品質や、実機のアナログ性能を証明するものではありません。測定数値はJSONに保存しています。

ERCやDRCを黙らせるための一括違反除外は設定していません。PCM3060の多機能端子はハードウェアモードに合わせてDEMPを入力として表現し、未使用端子はNCにしています。電源入力には意図を明示するPWR_FLAGがあります。

開発目標の目安はDRYアナログ往復3 ms未満、1 kHzでTHD+N −80 dB以下、A-weighted SNR 90 dB以上、各モードのDMA期限未超過です。これらは**受け入れ試験用の目標で、達成済み仕様ではありません**。ピッチ処理では品質と遅延の両方を記録して判断します。

USBのサスペンド電流、ESD/EMC、製品のVID/PID、部品代替、筐体機構は製品化時の追加作業です。現時点の `production_release` と `bench_validation` はどちらもfalseです。
