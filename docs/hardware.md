# ハードウェア設計

## 前提と対応範囲

Rev 0.1は、USB-CをPCまたはスマホに接続するUSBオーディオ「デバイス」、アナログはステレオラインレベル、6.35 mmは外付けアダプタという前提です。USBホスト、マイクプリアンプ、ファンタム電源、Hi-Z楽器入力、ヘッドホンドライバは含みません。ピッチ処理はMCU上のDSPで、純アナログや専用ASICによる無遅延変換ではありません。

信号経路は、ライン入力 → 減衰・AC結合・バッファ → PCM3060 ADC → SAI → STM32 DSP → SAI → PCM3060 DAC → 出力バッファ・AC結合 → ライン出力です。USB入力・出力はMCU内で選択します。出力先はLINEかUSBのどちらかで、非選択側にはゼロを送ります。

## 寸法・実装

- 外形98 × 98 mm。M3用3.2 mm NPTHが4個、穴中心は各辺から4 mm。
- 4層：L1信号・部品、L2 GND、L3 3.3 V、L4信号。最終板厚1.6 mmを想定。
- SMT 100部品、手付けヘッダ3個、取付穴4個。OLEDモジュールは別途購入・取り付け。
- 全部品をTOPに配置。ヘッダのはんだ付けは裏面から行います。
- 外形寸法はPCB単体。ジャック、USBコネクタ、ケーブル、筐体の寸法は別途確認。
- OLEDの予約枠は28 × 21 mmの参考表示。特定モジュールの外形・取付穴を保証しません。ピン順と高さを確認し、必要に応じて短いケーブルで取り付けます。

## アナログ電気仕様

|項目|設計上の値・制約|
|---|---|
|入力|3.5 mm TRS、Tip=L、Ring=R、Sleeve=GND、非平衡ステレオ|
|入力インピーダンス|約20 kΩ。外部出力の負荷能力を確認|
|入力レベル|公称1 Vrms程度。分圧後ADC 3 Vpp基準で約2.12 Vrmsが理論上限|
|出力|同じTRS配線。各ch 100 Ω直列、10 µF AC結合、100 kΩ放電抵抗|
|出力負荷|10 kΩ以上を想定。低インピーダンスのヘッドホンは非対応|
|出力振幅|片側DAC出力4 Vpp基準で約1.41 Vrmsの理論上限、負荷で低下|
|DRYの利得|入力1/2分圧とADC/DACフルスケール比より約2/3、−3.52 dB。ユニティゲインではない|
|フィルタ|入力RFフィルタ、ADC手前100 Ω/2.2 nF、DAC後3.3 kΩ/1 nF|

ADC入力は4.7 µFでAC結合し、VCOMから100 kΩでバイアス、TLV9062でバッファします。DACの正側出力を使い、負側は未接続です。データシートの差動DAC性能値をこの片側出力基板の実測値として扱わないでください。

TRSは平衡モノラルではありません。モノラルTSプラグや平衡出力を接続する場合、左右・グラウンドの配線を適切に変換してください。通常の6.35 mmステレオTRS変換アダプタはステレオライン用です。入力ジャック側に専用の音声用ESD保護素子は未実装で、製品化時には耐性評価・対策が必要です。

## コーデックとクロック

PCM3060はハードウェア制御、I²S 24 bit、ADC/DACともスレーブです。MODEは220 kΩ経由で3.3 V、IFMD/FMT/DEMPはGND。ADCとDACのMCLK/BCLK/LRCKは共通です。RSTには10 kΩプルダウンがあり、MCU起動中はリセットを維持します。

8 MHz CMOS発振器をHSEバイパスへ接続。PLL1でCPU 400 MHz、PLL3でSAIクロック約49.152008 MHzを生成し、MCLK=12.288002 MHz、48 kHzを得ます。PLL分周値の公称誤差は約+0.164 ppmですが、実際の絶対精度とジッタは発振器・PLL・基板に依存します。USB PHYはHSI48をUSB SOFでCRS補正します。

SAIは64 bit/frame、BCLK=3.072 MHzを想定。MCUのSAI1 Aをマスター送信、Bを同期受信にし、ADC/DACの24 bitデータを32 bitスロットで扱います。音声クロックを開始して50 ms後にコーデックのリセットを解除します。

## 電源

USB VBUS → 500 mA PTC → TPS22918スルーレート制御 → 5 V。TPS22918のCT=10 nFで約26 msの立ち上がりを想定し、バルク容量の突入電流を抑えます。VBUS直結側の意図した容量は約1.1 µFです。USB給電試験は未実施です。

5 VからLD1117S33で3.3 Vを生成。ADC/DAC・オペアンプのアナログ5 VとMCU VDDAはフェライトで分離します。1117には安定性に必要な電解出力コンデンサを使用します。電流・ESR・温度・突入電流は試作時に測定してください。0.3 A時のLDO損失は概算0.51 Wで、銅箔放熱と筐体温度の確認が必要です。

CC1/CC2には独立した5.1 kΩのRdがあり、MCU ADCでRp広告電流を判定します。USB構成完了で500 mAが認められたホスト、またはType-Cの1.5 A/3 A広告がある電源で音声処理を開始します。それ以前はCPUをHSI64へ切り替えた待機状態です。待機100 mA以内・USBサスペンド電流への適合は未確認で、USB規格認証済みではありません。5 V固定、PDの9 V以上の要求は行いません。

USB-Aの充電器にA-Cケーブルでつなぐだけでは、データ通信なしで動作開始できない場合があります。スタンドアローンには5 Vで1.5 A以上を広告するType-C電源とC-Cケーブルを使用します。本基板にはバッテリー・充電回路・外部電源切替はありません。

## 主要ピン

|信号|MCU GPIO / 100ピンLQFP物理端子|
|---|---|
|MCLK / ADC data / LRCK / BCLK / DAC data|PE2/1、PE3/2、PE4/3、PE5/4、PE6/5|
|Codec reset|PC6/63|
|USB D− / D+|PA11/70、PA12/71|
|CC1 / CC2 sense|PC0/15、PC1/16|
|USB VBUS software sense|PA9/68、100 kΩ/100 kΩ分圧。TinyUSBはbus-powered B-valid overrideを使用|
|OLED SCL / SDA|PB8/95、PB9/96|
|MODE / DOWN / UP / I/O|PD8/55、PD9/56、PD10/57、PD11/58|
|Status LED|PB0/34|
|SWDIO / SWCLK / SWO|PA13/72、PA14/76、PB3/89|
|UART TX / RX|PB10/46、PB11/47。予約端子、現ファームウェアにUART CLIはない|

J4 OLED: 1=GND、2=3.3 V、3=SCL、4=SDA。3.3 VのSSD1306、I²Cアドレス0x3C、128×64専用です。SH1106や0x3Dはそのままでは使えません。

J5 SWD: 1=3.3 V reference、2=SWDIO、3=SWCLK、4=GND、5=NRST、6=SWO。J6 UART: 1=GND、2=TX、3=RX。USB給電とプログラマからの二重給電は避け、J5の3.3 Vは電圧検出に使います。

## 配線上の未確定事項

一般クリアランス0.15 mm、配線幅0.20 mm中心、ビア0.60/0.30 mm。L2のGND面を保ち、信号は表裏に配線しています。USB D+/D−の銅箔長合計差は約0.26 mmですが、同一間隔で結合した90 Ω差動配線として設計・検証したものではありません。層構成の誘電体厚さ・銅厚も製造先と未確定です。USB信号品質、クロック波形、リターン経路、ADCノイズ、デカップリングとLDOの温度をレビューしてから試作発注してください。CAD上のDRC通過だけではこれらを検証できません。
