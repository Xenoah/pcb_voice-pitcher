# Voice Pitcher Rev 0.1 — engineering prototype

98 × 98 mm・4層・表面実装のスタンドアローン音声DSP基板です。スクリーンショット全18枚を本文とAssetsに掲載しました。

これは実機未検証のプレリリースです。ERC/DRC/未接続は0件、ファームウェアのビルドとDSP合成音テストは通過しています。音質・遅延・USB互換性・消費電流は未測定で、量産承認済みではありません。

Assetsには全データZIP、ガーバーZIP、BOM/CPL、回路図、日本語説明書、ファームウェア、画像ZIPと個別PNGを含みます。`voice_pitcher_rev0.1_prototype.zip` でソースと製造資料を一括取得できます。部品調達とCPL方向のレビューを済ませてから試作してください。


実際のKiCadデータとPDFから出力した設計画面です。実機写真ではありません。3Dモデル未提供のJ1（USB-C）、J2/J3（音声ジャック）、Y1（発振器）、および外付けOLEDは3D表示に含まれません。
