# 製造・調達手順

Rev 0.1の出力は**試作レビュー用**です。製造発注・部品購入は自動実行していません。CADルールの通過と、部品の調達・実装・電気的動作の保証は別です。

## ファイル

|ファイル|用途|
|---|---|
|voice_pitcher_gerbers.zip|F.Cu / In1.Cu / In2.Cu / B.Cu、表裏マスク、表シルク、表ペースト、外形、PTH/NPTHドリルとマップ|
|jlc_bom.csv|SMTのみの33部品グループ、100個。LCSC欄が空のものは手動照合が必要|
|jlc_cpl.csv|SMT 100個、全てTop。穴と手付けヘッダは除外|
|bom_master.csv|107項目、MPN、LCSC候補、調達確認状態、参照URL|
|additional_parts.csv|基板に載らないOLED、電源、ケーブルなど|
|assembly-top.pdf / svg|表面の部品番号、ピン1、極性、OLED参考枠|
|schematic.pdf|7ページの回路図|
|reports/|ERC/DRC、端子照合、DSPテスト結果|

`downloads/fabrication/` にガーバーとドリルの展開済みデータもあります。ガーバーとCPLは同じ配線済みPCBから生成します。CPLの原点は**基板左下、X右向き、Y上向き、単位mm**です。配置角度はKiCad角度を0～360°へ正規化した値です。

## JLCPCB指定の出発点

- PCB 98 × 98 mm、4層、1.6 mm、FR-4。表面のみSMT実装。
- L1=F.Cu、L2=In1.Cu GND、L3=In2.Cu 3.3 V、L4=B.Cu。
- 一般的な製造能力内の0.15 mm最小クリアランス、0.60/0.30 mmビア。
- 表面ペーストのみ。ヘッダ3個とOLEDは手付け。
- 表面処理、層厚、銅厚、パネル化、搬送レール、工具穴、フィデューシャルは実装会社と確認。現基板には専用グローバルフィデューシャルを追加していません。
- 制御インピーダンスを確定していないため、90 Ω指定だけでこの配線が自動的に適合するとは扱わないこと。

JLCPCBの部品モデルの0°とKiCadの0°は一致するとは限りません。CPLアップロード後、**全ICのピン1、ダイオード、電解コンデンサの極性、USB、音声ジャック、スイッチの向きを組立プレビューで照合**してください。向きの補正は実装会社のプレビューに合わせて行います。自動実装用の方向確認は未完了です。

## 部品調達の状態

2026-11-01に確認したページを根拠として記録しています。在庫・価格・Basic/Extended区分は変わります。

|状態|個数|意味|
|---|---:|---|
|BASIC|53|主に抵抗と100 nF。JLCPCBのBasic表示を確認した候補|
|JLC_LISTED|9|JLCPCB掲載を確認。Basic区分・購入時在庫は保証しない|
|LCSC_LISTED_JLC_UNCONFIRMED|1|PCM3060PWR。LCSC掲載は確認、JLC実装の選択可否は未確認|
|UNVERIFIED|37|MPNを指定したがJLCの一致候補を未確定|
|HAND|3|手付けヘッダ|
|MECHANICAL|4|取付穴、電子部品としての購入不要|

53/100個のSMTをBasic候補へ寄せていますが、**全品標準部品での実装ではありません**。STM32H743、PCM3060、低雑音アナログ回路の部品を価格だけで置き換えないでください。

主な候補：STM32H743VIT6=C114409、USBLC6-2SC6=C7519、TYPE-C-31-M-12=C165948、PCM3060PWR=C2651841（JLC未確認）。BOM内のURLとメーカーMPNを照合します。未確認部品についてはJLCのGlobal Sourcing/事前購入/部品持込などの可否を確認するか、互換品を設計レビューしてから置き換えます。

## 注文前に完了すること

1. 電源・クロック・USB・アナログの回路/レイアウトを設計者がレビュー。特にUSBインピーダンス、LDO放熱、入力ESD、デカップリング。
2. UNVERIFIED全品とPCM3060の調達、パッケージ、フットプリント、極性を確認。抵抗値だけで自動置換しない。
3. UWT電解コンデンサの缶径・高さ・ランド、CUIジャックのS/T/R番号、TL3342スイッチの端子共通関係をメーカー図面と照合。
4. OLEDの3.3 V動作、SSD1306、0x3C、ピン順、外形、高さを確認。ヘッダは別途実装。
5. ガーバービューアで4層順序、閉じた外形、PTH/NPTH区別、マスク、シルク、ペーストを確認。
6. BOM/CPLの100個が一致することを確認し、JLC組立プレビューで向きと極性を照合。
7. まず少数の試作を行い、電流制限電源で立ち上げ。[実機検証](validation.md)後に量産判断。

## 設計変更後の再生成

通常はKiCadで配線済み基板を編集し、チェックして再出力します。部品や配線を変更したら `tools/design.py` の端子情報・配置と回路図も合わせて更新してください。チェックツールはこの不一致を検出します。

```sh
make hardware-check
make exports
python3 tools/package_release.py
```

ゼロから設計ソースを再生成する場合は `/usr/bin/python3 tools/generate_hardware.py`、次に `tools/prepare_routing.py` を実行します。後者は配線済みPCBを下書きで置き換えるため、編集済み基板をコミットしてから使います。`build/voice_pitcher.dsn` をFreerouting 1.9.0で配線し、`build/voice_pitcher.ses` を `tools/import_routing.py` で取り込みます。元のルーティングは最大30パス、最適化1スレッドで実施しました。再配線結果は同一とは限らないため、再度ERC/DRC・端子照合・レイアウトレビューを行います。
